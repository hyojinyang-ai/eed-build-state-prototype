# FictionUI icons

PNG exports of all 211 reusable icon component definitions found on the Figma `Icons` page (node `70:3`).

## Usage

Use an icon directly from the static HTML prototype:

```html
<img
  src="assets/figma-icons/001-icon-large-settings--4727-16711.png"
  width="20"
  height="20"
  alt=""
>
```

Decorative icons should use an empty `alt` attribute. For icons that communicate meaning without a visible label, provide a concise accessible label.

See `manifest.json` to find assets by their original Figma component name or node ID. Filenames include a numeric export index and node ID because some Figma variant names repeat.

## Source
