## Capture note

The live browser used for the replay is a virtual browser surface. Its screenshots can be displayed in the conversation, but the available browser bridge does not expose a filesystem-write operation for those image bytes. An operating-system screen capture saved the unrelated desktop rather than the virtual browser, so no desktop capture is presented as a valid prototype screenshot.
